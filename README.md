## Versionamento Semântico

O Versionamento Semântico  é uma forma
padronizada de definir e identificar as versões de um projeto.

O formato utilizado é:

MAJOR.MINOR.PATCH

### MAJOR

Deve ser incrementado quando forem realizadas alterações incompatíveis
com versões anteriores do projeto, causando possíveis problemas de
compatibilidade.

### MINOR

Deve ser incrementado quando uma nova funcionalidade é adicionada de
forma compatível com as versões anteriores.

### PATCH

Deve ser incrementado quando são realizadas correções de erros ou
pequenos ajustes compatíveis com a versão atual.

### Exemplo

A versão 1.0.0 representa a primeira versão do projeto.

Quando uma nova funcionalidade compatível for adicionada, a versão pode
passar para 1.1.0.

Quando for realizada apenas uma correção de erro, a versão pode passar
para 1.0.1.

Quando houver uma alteração incompatível com versões anteriores, a
versão pode passar para 2.0.0.
